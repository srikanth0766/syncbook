# UI  Design Guide — SYNCBOOK

Follow this document for the visual design of the Syncbook Booking Channel frontend.

## Design Philosophy

* Clean and modern hotel booking experience.
* Minimal and premium.
* Generous whitespace.
* Typography-led design.
* Simple, clear layouts.
* Avoid generic SaaS dashboard design.
* No gradients or glassmorphism.
* Minimal shadows.
* Use subtle borders.
* Primary buttons can be pill-shaped.
* Keep cards and UI elements simple.
* Use subtle animations only.

## Colors

* Background: `#FAFAF8`
* Primary text: `#111111`
* Secondary text: `#6B6B6B`
* Surface: `#FFFFFF`
* Borders: `#E5E5E0`

Use one subtle accent color.

Do not use too many colors.

## Typography

* Large headings.
* Clean sans-serif for UI.
* Strong hotel and room names.
* Small uppercase labels where appropriate.
* Clear visual hierarchy.

Use:

* Inter
* Helvetica Neue
* System sans-serif

## Layout

* Spacious.
* Clean.
* Easy to scan.
* Focus on hotel, rooms, dates, and bookings.
* Use borders and spacing to separate sections.

## Buttons

Primary:

* High contrast.
* Pill-shaped.
* Clear text.

Secondary:

* Simple.
* Border-based.
* Minimal styling.

## Cards

* Simple white surface.
* Thin border.
* Minimal or no shadow.
* Avoid excessive rounded corners.

## Motion

* Fast.
* Subtle.
* Fade and small transitions only.
* 150–300ms.

No heavy animations.

## Responsive Design

Support:

* Desktop.
* Tablet.
* Mobile.

Keep the booking experience clean and easy to use on all screen sizes.

## Final Goal

The frontend should feel like:

A modern, clean, premium hotel booking website.

Simple.

Minimal.

Easy to use.

Not a SaaS dashboard.
